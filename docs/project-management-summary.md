# CyberShield Project Management Summary

## Overview

The CyberShield project required coordination across multiple technical and documentation workstreams. The project was completed as part of NCyTE's Virtual Cybersecurity Career Challenge (VCCC), where the team built a simulated enterprise infrastructure environment for a B2B cybersecurity services company.

The project required planning, task tracking, implementation, technical documentation, security assessment, and final presentation preparation.

## Project Goals

The major project goals were to:

- Design a realistic enterprise infrastructure environment
- Build a segmented network architecture
- Deploy firewall and routing infrastructure
- Implement Active Directory and DNS services
- Deploy a DMZ-hosted web application
- Build database-backed business functionality
- Integrate an AI chatbot workflow
- Implement infrastructure monitoring
- Configure internal email services
- Document the full environment
- Complete security assessment and vulnerability planning
- Prepare the project for final presentation and handoff

## Workstreams

The project was divided into several major workstreams.

| Workstream | Description |
|---|---|
| Business Concept | Defined CyberShield as a cybersecurity services and products company |
| Network Architecture | Designed segmented WAN, DMZ, transit, and LAN zones |
| Firewall & Routing | Implemented OPNsense firewalling and VyOS routing |
| Identity Services | Configured Active Directory, DNS, users, groups, and policies |
| Web Application | Built the CyberShield product/service platform |
| Database | Designed and tested MariaDB tables for orders, products, and AI leads |
| AI Integration | Integrated chatbot functionality and lead-routing workflow |
| Monitoring | Implemented Prometheus and Grafana visibility |
| Email | Configured internal hMailServer and Thunderbird clients |
| Workstations | Configured Windows and RHEL client systems |
| Backup & Recovery | Tested database backup and restore procedures |
| Security Assessment | Completed CSET/NIST CSF assessment and vulnerability planning |
| Documentation | Created the Network Configuration Record and supporting materials |

## Timeline Summary

The project timeline covered several phases:

1. **Planning and Design**
   - Defined the business scenario
   - Planned core infrastructure
   - Identified project workstreams
   - Created initial documentation structure

2. **Infrastructure Buildout**
   - Built network zones
   - Configured firewall and routing infrastructure
   - Deployed Windows and Linux systems
   - Configured Active Directory and DNS

3. **Application and Database Development**
   - Built the CyberShield web application
   - Designed database models
   - Implemented product, order, and AI lead tables
   - Tested database queries, backup, and restore procedures

4. **AI and Monitoring Integration**
   - Integrated chatbot functionality
   - Designed automated lead classification and routing logic
   - Configured Prometheus and Grafana monitoring
   - Created dashboard views

5. **Security Validation and Documentation**
   - Completed security assessment work
   - Documented firewall rules, routes, NAT, host roles, DNS, services, and dependencies
   - Prepared final documentation and presentation materials
